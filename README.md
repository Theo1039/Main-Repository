# Personal Library Manager
A collaborative CLI application for managing library records.

## Quick Reference: Python Concepts Covered
To build this application, we are utilizing the following core Python concepts:

* **Data Storage & Structure:** 
    * Lists `[]` for collections of books.
    * Dictionaries `{}` for representing individual book records.
    * JSON module for data persistence.
* **Control Flow & Interaction:** 
    * `while` loops for the main application menu.
    * `if/elif/else` statements for routing user choices.
    * Functions `def` for modularizing features.
* **User Input & Output:** 
    * `input()` for capturing user data.
    * f-strings for formatted display.
* **Error Handling:** 
    * `try/except` blocks to prevent crashes.
