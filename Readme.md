# ReverseString

ReverseString is a simple Go project that demonstrates how to reverse a string using basic Go concepts.  
It is designed for beginners who are learning Go syntax, functions, and string manipulation.

---

## 🚀 Features
- Reverses any given string
- Written in pure Go (no external libraries)
- Easy to understand and modify
- Beginner-friendly example project

---

## 🛠️ Requirements
- Go installed on your system (Go 1.18 or higher recommended)

Check installation:
```bash
go version
